# 工具任务的资源保护

执行命令时，567 Agent 对命令及其子进程设置内存预算，并限制返回的输出大小。超限会结束任务，聊天记录中的工具错误说明具体原因和缩小任务的方法。

默认单个命令预算是机器或容器总容量的四分之一，最高 8 GiB；当前宿主内所有命令的合计预算是容量的一半，最高 32 GiB。标准输出与错误输出合计最多 32 MiB。Linux 还在命令启动前限制可写内存分配；为兼容 Node 24 的虚拟 CodeRange 预留，该内核上限至少为 1 GiB（更低的继承硬限制仍保留）。配置的较小实际内存预算继续由进程树采样执行。Windows/macOS 使用定期进程监控。

启动时单命令预算还会限制在当前可用内存的一半，避免其他应用已经占用大量内存时继续分配。可用内存少于 64 MiB 时拒绝启动命令；执行期间剩余内存过低时结束最大的命令，保留应用与系统的运行空间。

AI 会被提示先检查 CLI 参数的单位，估算图片尺寸、瓦片数、数组与并发任务的内存。遇到保护错误时，应该缩小区域、降低分辨率、减少并发或分批处理。大量文本输出应写入文件，然后只查看所需部分。

## 调整预算

确实需要执行大型任务时，可在启动应用前设置以下宿主环境变量，重新启动后生效：

| 变量 | 含义 |
| --- | --- |
| `AGENT567_COMMAND_MEMORY_MB` | 单个命令进程树预算，MiB |
| `AGENT567_COMMAND_TOTAL_MEMORY_MB` | 当前宿主所有命令合计预算，MiB |
| `AGENT567_COMMAND_OUTPUT_MB` | 单个命令 stdout/stderr 合计上限，MiB |

只能设置正整数；不能用 0 关闭保护。内存预算最多为机器或容器容量的 75%，单命令预算不能超过合计预算；输出预算最高 256 MiB。模型给单条命令设置同名环境变量不会提高限制。

## 瓦片圈数与距离

`geo-sleuth` 的 `tiles.py fetch --radius` 表示瓦片圈数。默认 4 表示 9 × 9 个瓦片；每块 256 像素时，整张图片是 2304 × 2304 像素。它与同一 skill 中其他脚本以米为单位的 `--radius` 不同。

本机安装的该工具已添加分配前检查：圈数最多 15，画布每边最多 8192 像素、总计最多 64 Mi 像素；比较图和网格同样检查尺寸及候选数量。超限请求在下载和创建图片前退出，并把单位和调整建议作为工具错误返回给 AI。此补丁属于本机第三方 skill；后续第三方更新可能替换该文件，应用的通用命令保护独立生效。

## 保护范围

覆盖前台、后台、SDK 命令及受限沙箱命令。监控使用采样，不能保证拦住所有平台的瞬时分配，也不限制 GPU 显存和第三方远程服务。原有文件、网络和工具权限继续由各自的权限机制控制。详见 [ADR-0132](../adr/0132-command-resource-protection.md)。

超时、取消和超量输出会清理命令进程组；父进程退出后，仍持有输出管道的普通子进程继续受保护。SDK 和插件命令不会因子进程忽略终止信号而一直等待，信号退出也不会被当作成功。
