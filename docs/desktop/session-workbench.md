# 会话工作台与诊断

电脑输入工具栏的文档图标打开会话工作台；手机从会话右上角“上下文管理”进入“会话工作台”。两端更新后，手机可读取已配对电脑的工作台。

## 上下文

- 查看最近 100 回合的文字与附件预览，展开查看更长片段；完整聊天记录仍在会话。电脑可搜索回合内容或附件，批量包含/排除仅作用于当前搜索显示项；手机可批量处理当前展示的最近 100 回合。更早的排除设置会保留。
- 保存和还原操作固定在底部，正文单独滚动；未保存时关闭会先确认是否放弃。切换分页不会丢弃本次编辑。
- 取消勾选会排除完整回合，保留工具调用与结果的配对关系；可固定预览或自行填写重要信息（最多 16,000 字符）。保存后影响后续任务。
- 修改排除范围会重新整理此前摘要。摘要和原始记录都不会因此从聊天历史删除；下一轮可能重新触发自动压缩并产生用量。
- 手机 API 的筛选和摘要由手机保存；手机远程电脑会话交给电脑执行。模型容量仍在电脑设置修改，手机远程容量只读。
- 容量手动值优先于接口和参考资料；K/M 为十进制，Ki/Mi 为二进制。参考的温度、Top-P 和思考参数不会自动写进请求。

## 附件

待发送和历史附件集中查看，详情点击后加载。电脑工作台中列表和详情分别滚动，较窄窗口下详情替换列表，可关闭详情返回；预览原文件在独立弹窗打开，关闭后回到工作台。手机历史附件与任务详情单独打开，原文件保存操作保持可见。原文件保持原格式；文本最多预览开头 32 KiB，其他格式可在电脑使用已有预览器。

待发送文件可填写页码、章节或行号要求，该要求会连同原文件引用发送给 Agent，由其工具按需读取；“文件已存在”不等于“模型已解析”。手机 API 仍只支持图片，其他原文件需发送到电脑会话，TXT 不会被偷偷转为正文。

手机可从电脑保存会话中明确附加的原文件，单文件最多 12 MiB。下载分片并检查版本，原文件中途变化时会终止并提示重试；工作区外的符号链接、目录或已删除文件不会开放下载。

## 任务与修改

任务页显示已保存回合的状态、开始时间、总耗时、工具步骤和结果预览。查看、刷新和找回不重新执行任务。手机 API 断网后的状态不代表服务器能续接；如要重试，先检查已有结果以免重复调用。列表显示最近 200 回合，结果预览有长度限制，完整记录留在聊天中。

修改页复用差异预览，可保留修改。新版本原生 `edit` / `write` 对 64 KiB 内的 UTF-8 文件保存前后快照；有完整快照且当前文件仍匹配修改后版本时，电脑才开放撤销。撤销前保存恢复备份；文件被再次编辑则拒绝自动覆盖。手机可查看，撤销在电脑确认。大文件、新建文件、命令或外部工具没有完整快照时不提供自动撤销。

工作台配置位于会话文件旁的 `.context.json`，审阅标记位于 `.review.json`，撤销备份位于 `.review-backups/`。项目导出选择包含会话目录时会保留这些文件。手机加密备份保留手机上下文；导入电脑时将范围映射到新消息 ID。跨端迁移后自动压缩可能重新整理完整历史，不会重新执行原任务。

## 诊断与修复

电脑“设置 → 通用设置 → 诊断与修复”、手机“我的 → 数据 → 诊断与修复”可先检查并预览摘要，再导出。默认摘要不包含聊天、原文件或认证配置；附带近期日志需要手动开启，导出后请检查再分享。

电脑可修复不完整的 Node/npm 或 Python；文件占用时到“应用环境”使用“重启并修复”。远程配对/证书问题沿用远程连接设置处理，不会在一次自检中自动重置。模型和具体插件是否可用仍需实际连接或打开后验证，自检不提交付费推理请求。

## GitHub 下载源

电脑“设置 → 通用设置 → 更新下载源”、手机“我的 → 关于 → GitHub 下载源”可选 GitHub 直连、gh-proxy.com 或自定义 HTTPS 前缀。默认使用直连。自定义前缀示例 `https://proxy.example/`，应用会在其后拼接完整 GitHub 安装包地址；不接受账号、密码、查询参数或 URL 片段。

电脑保存后重启应用生效；手机保存后重新检查版本再下载。手机安装包由系统浏览器下载，版本信息仍通过匿名 GitHub API 查询。此设置不影响模型请求、账号服务或远程连接中继。

## 能力

能力页分类中选择“已安装”，可查看实际已安装的能力数量与项目，包含已从当前市场来源移除的本地能力；可继续按类型、名称与标签筛选。
