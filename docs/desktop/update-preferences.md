# 更新设置与更新说明

在「设置 → 通用 → 应用」查看版本、检查更新与调整下载源。新版本下载时显示百分比及已下载/总 MB；安装包准备和完整性校验继续由既有更新引擎处理。

- 自动检查可关闭；手动检查始终可用。可选 30 分钟、1 小时、2 小时、6 小时和 24 小时，默认保留原来的 2 小时。
- 唤醒及打开设置后的后台检查遵守同一间隔；手动检查完成后重新安排下一次自动检查。取消后旧响应和旧下载进度失效，退出时释放定时器与监听。
- 自动下载与侧栏提醒分别保存。关闭自动下载只影响尚未开始的下载；当前下载继续进行。关闭提醒后仍可从设置中安装。
- 重启安装需要手动确认。重启会中断活动请求，应先结束或停止任务；没有加入强制或定时自动重启。
- 下载源沿用 GitHub、gh-proxy 与自定义 HTTPS 前缀。改变下载源仍需重启生效，不改变安装包校验。
- 完整安装包支持最多四连接与分片续传，差分更新仍由既有引擎处理；来源不支持范围时回退单连接。下载行可暂停，继续时复用同一地址和摘要对应的片段。退出不自动清空片段；校验失败不会生成可安装结果。多连接不保证固定提速。

「更新内容」按版本展示官方 GitHub 的正式发布说明，可选上次更新以来，或最近 10/20/50/100 个正式版本。已安装与尚未安装有文字标记。首次启用版本记录时只能从当前版本开始，不推断此前安装历史；列表最多读取最近 100 个版本。请求失败提供重试与发布页入口，更新说明不作为安装包来源。

这些偏好与版本记录存于既有 desktop-config.json，并保留其他配置、账号和会话；不会重新索引或迁移聊天数据。

## 组件边界

UpdaterService 继续拥有检查、下载及状态机；共享 UpdaterPreferences 定义持久化和 IPC 合同。main 更新偏好在写盘成功后生效，所有 updater IPC 只接受所属主窗口的主 frame。

UpdatePreferencesSettings 负责 IPC、翻译和弹层生命周期；theme-ui 的 UpdatePreferencesView 与 UpdateReleaseHistoryView 只接收数据和动作。GeneralSettingsView 通过普通 children 组合新增设置行，未新增区域映射或结构开关；原有下载源与主题合同继续使用。
