# 项目普通会话协作

打开侧栏的项目名称或协作图标，项目页默认显示协作。已有的 AGENTS.md 在「项目规则」中，导出和活动面板继续可用。

## 开始

1. 在同一项目创建或保留各自独立的普通会话，名称可以任意，分别选好模型。
2. 在项目页加入成员、填写职责，按需授予「可修改」权限、选择统筹，启用后保存。默认新成员只读。
3. 也可直接在聊天中说：「让本会话负责统筹，产品讨论负责方案，检查记录负责只读审查。」AI会先查找确切会话并保存配置。遇到重名时需要指定对象。
4. 接着提出需求。AI可下发任务、询问成员、读取对方允许共享的历史，并整合结果。会话模型和个人上下文保持独立；一次性任务不必修改长期分工。

未指定统筹时，由发起需求的会话跟进。项目页展示职责、当前模型/状态和最近任务；点击成员可以回到原会话。未加载的会话可能尚无模型显示，执行前会按其原历史恢复。

## 运行控制

只读分析与审查可并行；写任务串行，命令须使用前台方式。显式后台命令和子代理派发不在共享目录写许可范围内，请使用参与会话协作。

「暂停」阻止新任务开始，已运行任务可以结束；「停止」取消排队并结束执行中的协作。单个任务详情可以停止/继续。人工直接向正在协作的会话发消息时，该协作回合会中断让位，不自动重试。

等待超时只表示还没有结果，不表示任务失败。AI已在当前回合读取过结果时不会再为同一结果自动开一轮回答。最多3轮审查修复；超限、失败或桌面重启后，请先检查产物/历史，再明确选择继续，避免重复修改或收费。

成员下发子任务后会显示「等待成员结果」，子任务完成后再汇总回传。汇总时继续下发的工作仍归原任务，只有后续工作处理完才算完成；只读任务的汇总也保持只读。多个独立结果会合并唤醒，减少重复调用。

任务区默认收起，展开后优先展示在途任务，先显示8项，可继续展开；完整需求、结果和错误在详情中查看。成员表可搜索，保存与暂停/恢复/停止操作固定在底部，长列表不需要滚到末尾才能保存。聊天中的协作提示保持简短，完整要求仍传给模型。

## 手机

手机连接电脑会话后，可在会话工作台的协作页查看同一配置、成员和任务，进行刷新、暂停、恢复及任务控制。自然语言分工仍在普通远程聊天中完成。电脑版本未提供协作能力或断网时会显示错误。手机直接调用API的会话暂不参与项目协作。

## 备份

全应用数据迁移包含协作数据。电脑导出项目或会话备份时会保留能与所选聊天对应的分工，导入时按聊天身份映射；缺失聊天不会绑定到同名的其他会话。运行中的工作在导入后保持中断，不会自动执行。旧手机本地备份格式中转不保证保留这些新增信息。

每个项目的协作档案最多32MiB、5000条任务，接近容量时会停止接收新任务并保留已有记录。请先导出备份，再使用新项目开展后续工作；界面只展示全部在途任务与最近200条已结束记录，较早记录仍保存在档案中。
