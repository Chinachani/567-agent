# 任务进度、继续执行与文件交付

电脑端 1.5 的对话输入区上方会显示当前任务状态。这里的状态来自正在执行的会话：等待模型、接收输出、运行工具、等待回答或授权、重试和整理上下文分别展示。本轮运行时间不代表预计剩余时间。

## 回复停止后如何继续

1. 点击“查看原因”回到本轮错误，展开详情，先处理网络、额度、模型配置或保存失败等原因。
2. 当前回合允许恢复时，点击“从历史继续”，阅读确认说明，再选择“确认继续”。新请求使用已有历史，输入草稿保留。
3. 有待发消息的队列被暂停时，先在输入区处理队列，选择继续发送或移除消息。目标模式通过原有目标控制恢复；可点击“查看目标”检查目标状态。

继续会发起新的模型请求并可能计费。客户端不重新提交原用户消息，也不回滚已经发生的外部操作。之前的网页提交、发送或付款状态不明时，应先检查实际结果，避免让后续操作重复执行。工具权限规则继续生效。会话保存失败时应先处理存储问题，新的继续入口不会绕过该错误。

正常回复结束后状态条收起，保留“从历史继续”入口；有可汇总内容时同时保留“文件与链接”。继续仍需明确确认，不会自动启动新请求。回复结束和目标被标记完成，都不等于文件内容或网站功能已验收。

## 在哪里找文件、网址和图片

点击输入区上方的“文件与链接”，或打开右侧活动面板，选择“交付”。可按全部、文件、网页和图片筛选，点击条目打开，直接复制路径或链接，也可通过“查看来源”回到对应消息。原有右键菜单继续提供默认浏览器、文件定位等可用操作。

- **对话引用**：助手回复或工具预览提到了该资源，尚未验证其存在或可用。
- **工具已写入**：工具成功报告了实际写入路径，文件名被自动纠正时使用实际路径。文件之后仍可能被修改或删除，内容正确性需要另外检查。

列表会从当前会话历史重建，大会话先显示加载反馈，再分批整理；切换会话后不会混入上一会话的结果。提取失败时可原位重新整理，聊天历史保留。

代码示例、用户附件和还在输出的文字不会作为交付列出。旧工具、shell 或插件没有报告输出路径、助手也没有引用的文件，可能不会自动出现在列表里；可以请助手在回复中补上文件链接。
