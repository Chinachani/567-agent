# 专家预设仓库与客户端同步

专家预设仓库是 [`Chinachani/567-agent-presets`](https://github.com/Chinachani/567-agent-presets)。
1.6 的入口为 **智能体 → 专家**：启动后读取本地快照并在后台刷新，也可在专家页手动刷新。
能力页的「市场来源」统一管理仓库地址与自动更新设置，但专家预设不进入普通能力的安装目录。

## 源码预设可以直接使用

首批 `everyday-experts` 包包含 18 位日常专家，源码提交为
`af824d994b7dc5acaefc87568dbc302809ebe6cd`。已核对的仓库使用
`.vetta/marketplace.source.json`，尚未提供 `gh-pages` 安装索引和 GitHub Release 制品。
客户端对这个明确识别的专家仓库提供受限的源码读取：从完整归档中校验专家声明、提示词、头像和译文，
不加载 `entry`、不执行模块联邦代码，也不替用户安装或启用插件。
普通第三方插件的构建、安装与授权规则保持不变。

专家详情展示实际提示词中的流程；点击「使用」只填入会话草稿，用户发送后才调用模型。
这些纯提示词专家默认不选择工具能力；复制后可以主动修改提示词与能力。
副本保存独立提示词和当时的能力选择，不受来源刷新、停用或原蓝图消失影响。
来源暂不可用时仍保留已知档案并说明原因，无法读取提示词的原件不能使用或复制。

## 同步与缓存

- 来源与普通 Skill、MCP、Plugin 市场分别缓存、分别显示状态。专家页显示刷新中、上次同步时间、缓存与失败原因；刷新不遮住本地专家。
- 有有效缓存时，网络失败继续使用上次完整快照。后台失败也会反映到专家页，可以手动重试。
- 支持服务端 ETag 时，使用完整归档的条件请求；304 仅在旧快照仍通过完整校验时复用。缓存损坏时重新取得归档并修复，服务端无 ETag 时正常下载完整归档。
- 内容身份来自完整归档摘要。即使仅修改提示词而没有改源码索引，也不会漏掉更新。
- 全部包和资源校验通过后才激活新快照；任何包不合格都保留旧有效快照，不把部分失败当作专家已删除。
- 来源停用或移除不会覆盖用户副本；完整有效的新声明才可收回旧的来源档案。早期 1.6 构建遗留的 `everyday-experts` 插件归属档案也受首次同步保护。
- 插件自身的安装、卸载和启停立即更新蓝图，不等待专家仓库的网络请求。慢请求返回后会再次核对来源身份，避免应用过期设置。

## 提示词包合同

沿用现有 `plugin.json` 的 `agent.agents`，没有新增虚构的 `expert.json` 或公共插件 API。
提示词在 `systemPromptPath` 或 `systemPrompt` 中声明，流程预览来自 `## Workflow` 下的编号行，
双语步骤采用 `English | 中文`。完整源码示例见专家仓库，普通插件示例见
[`preset-agent`](../packages/plugins/presets/preset-agent/plugin.json)。

受限读取拒绝符号链接、越界路径、过大资源、重复专家 ID、旧身份接管、团队声明、角色供应和额外权限、命令、MCP、技能或全局提示词贡献。
每包最多 128 位专家、32 份语言文件；提示词最多 64,000 字符且不超过 256 KiB，头像不超过 512 KiB。
名称和说明必须有有效默认语言内容，区域语言缺译时确定性回退。
这些约束只让已验证的提示词资源进入专家目录，不授予执行权限。

当前目录按规划、开发、研究、审阅、方案、写作、学习、职场、日常、自建与扩展分类。
首批 18 位专家按已核对的稳定 ID 分配类别；未知扩展继续归入扩展，不从提示词文本猜类别。

## 可选的正式插件分发

独立仓库后续仍可发布通用插件制品供其它客户端使用：

1. `main` 保存源码，通过 PR 审查提示词、流程与权限。
2. 构建真实插件入口并生成不可变 `.vettapkg` 和 SHA-256。
3. 生成 schema v3 的 `.vetta/marketplace.json` 到 `gh-pages`，填入制品摘要和兼容版本。
4. 提升版本发布变化，不能覆盖同版本字节或让索引指向缺失制品。

该分发流程与 567 Agent 的受限源码读取是两个入口；本轮未替独立仓库发布索引或制品。
完整插件分发合同见 [`open-marketplace.md`](open-marketplace.md)、
[ADR-0122](adr/0122-marketplaces-publish-generated-static-distributions.md) 和
[`plugin-cli/README.md`](../packages/plugins/plugin-cli/README.md)。
