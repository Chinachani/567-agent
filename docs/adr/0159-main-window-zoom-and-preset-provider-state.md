# ADR-0159 主窗口缩放与预设服务商启停

- 状态：已实现
- 日期：2026-11-09

## 背景

上游 `fc2bf1c..f52cefa` 增加缩放、预设开关与 Magpie。本地使用可信 renderer IPC、凭据库、567 API 线路和一级设置导航，不能直接覆盖这些边界。先前的预设组件也没有接到模型设置页。

## 决策

- 主进程持有六档缩放事实源，存入既有 Desktop 配置的可选 `uiZoomFactor`；缺省为 100%。所有变更串行执行，持久化成功后才应用主窗口和广播。辅助窗口不参与；IPC 检查主窗口来源与参数。Renderer 只保存临时滑块预览，订阅版本阻止迟到读取覆盖新状态。快捷键进入现有配置，不新增固定键盘监听。
- Provider 增加可选 `disabled`，缺省继续启用。停用保留模型、凭据引用与存储的默认选择；运行时、列表与新默认选择过滤停用项。模型覆盖值仍允许修改，不改正在执行回合的快照。重新启用恢复原配置，无磁盘迁移。
- 预设 UI 接入现有模型设置页，567 API 仍走专用分组/线路区域。修改前读取最新配置，按服务商合并，保留其他条目与覆盖值。凭据沿用本机凭据库，不向 renderer 返回真实密钥。
- Magpie 仅接受 HTTP loopback `127.0.0.1:<port>/v1`，不接受远程主机、凭据或 query/hash。拉取和持久化边界均校验；端口拉取失败不保存。模型行探测仅证明 HTTP 可达，不宣称已验证推理或鉴权。
- 通用 StepSlider 提供键盘与刻度交互，拖动提交与预览分离；保留现有思考菜单，不复活没有消费者的旧思考滑块。
- 旧 `release-desktop.mjs` 会把未经同 SHA CI 准入的候选与轻量标签一起推送。保留命令别名作为明确退出提示，移除其写入/提交/推送路径，使用现有版本脚本、官方 preflight 和 annotated 独立标签流程。

## 备选与影响

Renderer 各自保存缩放会造成窗口、快捷键、设置页不同步；直接采用上游菜单快捷键也会绕过可配置按键。删除 Provider 会丢失凭据和恢复信息，因此采用可选停用字段。任意地址编辑会改变凭据发送目标，故本机代理只开放端口。旧发布入口的本地检查不能代替远端同提交检查，因此不保留另一套发布实现。

不升级公共 RPC 协议，不移动历史或用户数据。旧配置缺省行为保持；没有真实模型调用。组件/宿主合同和隔离发布入口覆盖正常流程、失败重试与竞态。在临时 Xvfb 和空 profile 中验证 Electron 35.7.5 的发布版 file URL 窗口布局：主窗口 125% 时辅助窗口仍为 100%。未启动用户客户端，未进行完整安装包验收。
