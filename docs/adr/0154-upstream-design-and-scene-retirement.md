# ADR-0154：适配上游设计编辑器与下线场景功能

- 状态：已实现
- 日期：2026-11-02

## 背景

用户授权接入截至上游 `67127c684997fc56a8b75826f6d4b63402015d6d` 的更新，并确认不再需要场景功能。当前工作树还包含浏览器连接、模型调用预算、启动按需加载与文件预览修补，不能用上游整树替换。

## 决策

按能力组进行三方适配，使用 2026-10-28 的上游快照识别本轮增量，并补齐设计编辑器所需的前置模块。产品组合、Runtime、平台宿主与主题组件继续沿既有所有权边界；保留 567 的品牌、配置根目录、分享扩展名、模型和协议合同以及自己的 UI。

场景从导航、新会话、命令、能力市场、资源发现与执行链路下线。已有场景目录与会话原文不删除、不自动改写；旧定时与批量任务在创建模型会话前拒绝场景引用。用户明确编辑保存为普通任务时，使用 `skill: null` 清除旧引用；省略字段仍保留原值，调度 Capability 与插件 facade 同步该语义。旧引用保留可读降级，旧路由进入能力页。待办锁定仍由已有知识库流程使用，不随场景一起删除。插件与远控的旧序列化输入在已有边界兼容或明确拒绝，避免恢复场景执行路径。

设计编辑器接入尺寸预设、圆角、撤销重做、交互设备模拟与截图修补。操作撤销与设计文档版本历史保持不同职责；外部已修改的源码不可被撤销静默覆盖。引擎模板登记、内容哈希、资源打包和权限一起核对。素材库与设备样式的第三方来源和许可证随插件制品分发。

设计会话中的文件操作、撤销与同步画布编辑共享单个写入队列；撤销前再次检查当前源码，关闭后取消迟到的预览服务。分享包和内嵌历史在写入前统一校验相对路径、大小写碰撞与解压预算，Frame 文件路径只由经过验证的 ID 推导，保持旧设计格式可读。

上游发版辅助逻辑适配到本地双端版本和同 SHA CI 门禁，不采用其 dev/main 合并假设，不降低既有发布准入，也不在本次任务中发布。

## 备选方案

- 整树覆盖上游：会丢失现有工作树、567 配置与平台适配，放弃。
- 只接四个小修补：无法满足用户接入其余已确认更新的要求，也会遗漏设计功能前置依赖，放弃。
- 继续保留场景执行、只藏入口：会残留资源加载和公共合同的双重语义，放弃。

## 验证

先保留接入前源文件与摘要。覆盖旧历史读取、正常技能调用、待办与知识库、能力市场过滤、远控协议、新建与已有会话草稿、设置协议与浏览器连接、画布编辑/撤销冲突/导出/长图和引导流程；运行受影响包回归、类型与架构检查，并核对插件实际制品。
