# ADR-0165：任务结果、专家草稿与手机显式文件交接

日期：2026-11-17

状态：源码已实现，静态检查、生产编译与只读审查完成；未运行行为测试或设备验收。

## 背景

1.6 已提供专家来源、项目会话协作与手机任务跟进。用户还需要准备专家输入、交接已有成果、找回任务结果，以及不调用模型的文件传输。远控的连接阶段、画质与快捷输入也需要可见且可恢复的操作。

## 决策

### 专家输入和交接

- 收藏（最多 100）与最近打开（最多 20）保存在本机，跨桌面窗口接收 storage 变化；不保存提示词或凭证。
- 准备表单收集目标、材料、约束、交付要求，显示专家提示词中的 Inputs 提示；预览后追加为普通文本草稿，保留原附件与文字，不把其中的 `@` 解释成授权。
- 会话顶栏可以选下一位专家并填写阶段成果、待办、限制。只有显式点击才带入最近完整回复的文本块；不采集思考、工具原始载荷和系统消息。填写后进入同项目的新会话草稿，用户发送才调用模型。交接块标注目标专家，保留现有按项目隔离的草稿合同；完全相同的尾部交接块不重复追加。导航失败后冻结已保存内容，用户可重试打开，不回滚或覆盖其它草稿编辑。此桌面草稿仅在当前窗口内存保存，刷新不恢复。

### 任务结果

- 桌面从原生会话的持久化 turn 事件投影，当前文档分支决定用户请求是否仍存在。retry/continue 合并到原请求，最后一次 attempt 决定终态；转移源不重复展示。续接文件以 continued turn 身份建立本文件内的结果。
- 不把模型子循环结束、窗口关闭、通知阈值或修改时间当作任务完成。独立后台工具任务不纳入本收件箱。
- `FileConversationRepository.readSnapshot(sessionId, {maxBytes})` 是公开只读 API：同次有界读取生成事件与文档投影，不获取写锁，不恢复或修复日志。消费方前后核对 stat，变化或尾行不完整则下次刷新。
- 最近 200 会话、200 结果；单文件 16 MiB，累计读取 64 MiB，扫描 15 秒预算。按文件状态缓存投影。预算或单项错误明确报告部分结果。
- Desktop 已读台账为正式配置（最多 1000），Android 结果快照最多 500，按设备＋会话＋任务识别；终态变化重新未读。Android 退出时清理结果快照，删除会话或解除配对清理对应记录；保留会话的选择仍由现有退出流程决定。
- 手机本地结果从已保存 user/assistant 消息生成；无回复保留未知状态。运行状态仅覆盖尚未结束的最新请求，不把上一条完成任务重新标为进行中。
- 可选 `session.results.list` 通过既有 `session.context` 扩展信封协商，旧电脑不支持时保留已有快照。传输不含主机路径、消息正文或原始异常，已读状态各端独立。

### 文件分享与独立上传

- Android 系统 SEND/SEND_MULTIPLE 只读取系统授予读权限的 `content://` URI，在 IO 调度器读取。单文件 12 MiB、最多 10、合计 48 MiB；文本 10 万字符。读取失败明确告知；超过文本上限整份拒绝（包括该单附件），不截断或仅保留文件。Activity 最多保留 3 份待读取 URI 元数据并串行读取；VM 当前与排队分享合计最多 3 份、文件合计 48 MiB，处理或取消当前分享后推进，超限明确拒绝新增项，退出账号推进进程内分享代际，同时清空 VM 队列、取消 Activity 旧代际读取及待读 URI；读取完成和 VM 接收都核对代际，旧确认回调按分享 ID 不能清掉新内容。队列只驻内存，不跨进程恢复。字节不写入 Intent/保存状态 Bundle，不后台上传。
- 系统分享先选会话草稿。异步读取前后检查账号身份；合并最新草稿、保留原附件。容量不足保留待放入内容。新手机会话仍需账号登录；保存失败沿既有草稿恢复提示保留内存内容。
- 电脑会话「工作目录」支持选件、开始、进度、取消、重试；已确认文件不重复传输，可复制相对路径或追加草稿。
- 复用摘要与分片传输，start 增加可选 purpose（缺省 prompt）。可选 `session.file.transfer.finish` 用扩展信封完成 file 用途，必须与 start 相符。独立上传将图片也落盘，不占待发 prompt 附件池，不触发模型。
- 写入位置只能是会话执行文件系统的 `.567agent/remote-attachments`，文件名由主机生成随机前缀，不覆盖已有文件。本机拒绝附件父目录链接并核对规范路径；SSH 沿用远程路径边界。只返回相对路径与字节数。
- 最后确认响应丢失时不声称成功，也不自动重传；界面提示先检查电脑目录，用户重试可能产生副本。取消保留已经保存的文件，不承诺撤销正在完成的主机写入。退出面板会取消未完成请求。

### 远控体验

- 结构化面板区分连接、等待共享、协商、接收、恢复与结束，列出路径、RTT、FPS、分辨率、缓冲与解码估计。host-host 不保证同一局域网，估计接收延迟不等于端到端延迟。
- 复制诊断只用白名单测量值，不包含 IP、SDP、连接 URL、凭证或原始错误。
- 手机保存自动／流畅／清晰偏好。电脑收到已验证的可选偏好消息后调整发送策略；旧电脑不支持时禁用选择。流畅仍受真实源尺寸、编码器与压力降级限制，不承诺固定分辨率或帧率。
- 常用按键可选与排序；组合键按下、逆序释放，沿用输入授权与松键恢复。手机剪贴板仅在点击时读入可编辑输入框；电脑粘贴键仍使用电脑剪贴板。超长文字保留草稿并提示，不自动分批执行。

## 备选方案与代价

只汇总通知会遗漏短任务且无法恢复，因此采用持久化事件；扫描复用独占仓库接口会与写入争锁，因此新增无锁观察快照。直接把旧附件 finish 结果作为独立上传成功会使图片仍在内存、缺少落盘路径，因此增加能力协商后的明确完成操作。
