# ADR-0135：既有项目普通会话协作

状态：已实现；2026-10-17。

## 问题与不变量

用户需要把任意命名的既有项目聊天分工协作，保持每条聊天的模型、参数、提示词、历史、上下文选择和侧栏位置。已有 Agent Team 对成员有独立归属和目录过滤，直接把普通聊天迁入 Team 会破坏这些不变量。仅将分工追加到 AGENTS.md 则无法提供可靠队列、配置版本、取消和完成状态。

## 决策与职责

采用应用拥有的项目协作领域，复用 DesktopConversationService 的普通聊天创建、恢复、发送入口及同一 RuntimeHost。配置和任务使用版本化 JSON、原子写和按项目串行更新，存于567数据目录下，以规范化项目路径哈希隔离。AGENTS.md继续独立作为项目规则。

协作配置、任务状态转换、目录/公共历史读取、执行调度、宿主写许可和模型工具分别归独立模块。IPC只校验边界并转发；项目视图通过controlled props呈现，hook负责异步状态与项目身份。普通聊天工具只在已注册项目装配，能力白名单仍按原 Agent Profile/场景生效。

Coding Agent仅增加已有ToolPolicy的可选宿主授权函数转发，不认识项目协作、桌面配置或任务类型。相较在应用层只修改activeToolNames，这条授权路径可覆盖动态启用的工具、插件和命令，避免绕过只读任务和项目写许可；未注入的CLI/IM等宿主行为不变。

手机请求复用协议v1中已经协商的session.context扩展封套，电脑从授权会话位置解析项目，不接收客户端任意cwd。桌面工程和手机直连API的协作能力不共用隐式状态。

## 执行、取消和循环边界

- 目标会话忙时排队，每项目最多3个自动回合、最多1个写任务。所有已装配普通会话的写工具还经过同一个项目写许可，分析/只读审查可并行。
- 写许可持有至回合结束；派发/等待时释放，避免上级等待下级而占住目录。显式后台命令和子代理派发会被拒绝，防止其生命周期逃出当前许可；模型被要求使用参与会话和前台命令。
- 人工直接发言中断该会话的协作回合，等待实际停止，再处理人工消息；任务转中断，不静默恢复。
- 停止可以作用于项目或任务分支，取消排队任务、终止执行并等待退出。暂停只阻止新回合，已有回合可结束。
- 任务持久化先于执行；完成持久化失败只记录错误，不把已完成的付费工作重新执行。
- 结果由原发起会话消费；wait/read按结果版本消费，合并通知仍保留未读取的兄弟结果，防止重复模型调用或漏读。通知仅存储不唤醒模型，结果回合不向结果提供者发送无意义回复。
- 逻辑任务可处于waiting，不占用模型执行槽。成员派发子任务后等待结果，再以自己的模型汇总并回传原发起者；汇总时新增的工作仍归原逻辑任务，继承原只读限制，不提前完成上层任务。同一批子任务完成后合并唤醒。
- 完整任务要求作为隐藏模型上下文注入，聊天只显示本地化短提示；项目任务详情保留完整目标、结果和错误。八个模型工具分别负责发现、配置、控制、派发、消息、公共历史、任务读取和等待。
- 审查/修复最多3轮，单根请求最多32个自动任务，超额转为待处理。聊天工具的稳定requestId在同一源回合去重。
- 重启将排队/执行/等待任务标为中断并暂停，必须由用户检查后明确继续。继续请求提示模型检查已有历史/文件、保留已完成工作，不自动重放原请求。
- 自动恢复成员复用普通会话空闲驻留回收；可见、手工执行和协作执行中的会话受保护，执行完全释放后才重新参与回收。

## 数据与权限

配置更新使用revision避免覆盖；任务更新不会抬高配置revision。移除成员、禁用或收紧权限前要求关联在途任务完成或停止。公共历史只投影用户文本、最终回答和附件引用，原始思考、工具结果和子代理执行不暴露。历史和同行消息是数据，不能授权更改配置；自动同行回合在宿主侧禁止调用配置写入。

项目压缩包和电脑会话迁移保存便携协作信息，导入后验证/重映射聊天、根请求和结构化结果引用身份并中断在途工作。导入失败只回滚本次增量，不覆盖同期任务。未知Schema或损坏内容明确失败。全应用数据位置迁移自然涵盖该数据目录；不承诺经旧手机本地备份格式中转后保留新增协作元数据。

协作档案上限32MiB、5000条任务，派发前预留完成结果空间；达到上限明确要求备份后使用新项目，不静默丢弃记录。历史读取和任务结果分页，UI保留全部在途任务以及最近200条终态记录。

## 代价与验证边界

不额外引入团队运行时或固定角色模板；任意职责仍需模型理解，宿主只保证边界与执行状态，不能保证模型对自然语言任务的判断质量。前台命令仍可执行用户原有权限允许的操作，不是针对恶意代码的独立安全沙箱。

本轮按上级约束只进行静态检查和两端源码编译，没有新增/运行行为测试或真实付费协作、实机UI测试。这些检查不能证明全部异步时序和各Provider的实际工具调用行为，交付时明确保留验收范围。
