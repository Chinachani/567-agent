# ADR-0155：分页 MCP 目录的渐进查询与有界缓存

- 状态：已实现
- 日期：2026-11-03

## 背景

能力库 v2 不再限制全目录容量。旧客户端把所有摘要转成常驻 Renderer 数据，无法继续随目录增长。ADR-0127 的发现/安装隔离、已有有效缓存和 v1 安装流程必须保留。

## 决策

- 优先解析 catalog 分支完整 SHA，从该 SHA 读取 v2 根、页、摘要与详情。仅根 404 自动尝试同 SHA 的 v1；其它错误保留有效缓存并提示失败。v1 的总量门禁保持，v2 仅实施单文件及结构边界。
- 主进程拥有搜索生命周期、分页链校验、最多 4 个下载和 200 MiB 磁盘 LRU。缓存放在现有 marketplace 命名空间，按仓库、revision、路径、摘要隔离；不保存安装凭据或配置。根保留当前与上一代，协议选择单独记录以维持重启后的回退状态。
- 分类和六维 facets 只排除不可能命中的范围，实际摘要做组合条件匹配。关键词扫描未加载页，完整描述不参与普通检索。单片失败保留其它有效结果，重试复用校验缓存。
- Renderer 先呈现查询状态，绘制后启动 IPC；每个源仅保留当前 60 条窗口。目录候选有独立进度和前后翻页，已审核能力保留现有列表与安装方式，避免将当前窗口当作目录全集。换条件、关闭页面、窗口销毁与来源变更取消旧任务，迟到事件不能覆盖新条件。
- 新查询/取消和带定位的详情 IPC 限于可信主窗口主 frame。定位必须从已验证页重新解析；未审核候选固定只读、空配置，安装器只消费原可安装清单。
- 原磁盘 v1 缓存、安装台账、用户模型与线路配置不迁移不删除。新增 optional preload 字段；旧 v1 页面继续原搜索路径。

## 备选方案

- 扩大旧索引总量上限：仍产生常驻全集和首屏内存成本，不能满足扩容需求。
- Renderer 下载与验证分片：网络、缓存、安全与生命周期职责分散，且阻塞交互。
- 远端全文搜索：生产端没有该 API，本轮使用协议已有的摘要扫描。

## 后果与验证

首次全文搜索仍需读取相关范围的摘要，网络失败时不会声称全量完成；完整详情只在打开时下载。安装资格不由发现目录授予。测试覆盖官方原字节夹具、链式分页、跨旧容量、离线缓存、故障重试、取消、IPC来源以及页面连续操作；最终结果见本轮核对记录。

2026-11-03 验证：使用生产加载器固定 catalog 提交 `a1d36f8ff317aca886c892e6cb2298b09ec7c5bf`，完整扫描 12 类、68,492 条记录，零失败；搜索阶段未下载详情，打开一条记录后仅下载对应详情分片。模拟目录以 100,651 条、251 个分片和超过 100 MiB 的详情数据验证旧总量限制已解除。完整检查及受影响四包回归通过（4,161 例通过、4 例既有跳过）；本轮未打包或启动真实客户端，未改用户安装与配置。
