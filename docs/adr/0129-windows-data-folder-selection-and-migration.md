# ADR-0129：Windows 安装器支持独立数据目录

- 状态：已接受
- 日期：2026-10-12

## 背景

Windows 安装目录只影响程序文件，567 Agent 的会话、模型配置、技能、插件、凭据文件、Electron 用户配置和自动更新内容仍分散在用户配置目录及 `%LOCALAPPDATA%`。系统盘空间不足的用户无法把这些长期数据一并放到其他磁盘，旧用户也需要在选择新位置后安全迁移。

## 决策

1. Inno 安装器保留程序安装目录选择，并新增独立的数据目录页面。首次安装默认使用 `%USERPROFILE%\.567agent`；后续安装读取 HKCU 下保存的数据目录，用户可再次选择位置。
2. 安装器将 `.567agent` 主数据、旧 `.vetta` 主数据、Electron 的 `%APPDATA%\567-agent` 配置、Windows 更新版本目录和 electron-updater 差分缓存复制到选择的数据目录。复制使用系统 `robocopy`，不删除来源；失败时中止安装并显示错误，用户可检查空间或权限后重试。
3. 安装完成后，HKCU `Software\567Agent\DataRoot` 记录新位置。安装目录中的原生启动器读取该值，并向 Desktop 主进程传递 `AGENT567_HOME`、Electron 用户数据目录、更新目录和 updater 缓存目录。Electron 的 `userData`、`sessionData` 与日志路径都明确放在所选数据目录下。
4. 自动更新继续使用已登记的数据目录，不弹出位置选择页。安装器升级产生的版本文件、更新状态和差分缓存写入选定磁盘。
5. 卸载只清理自动更新文件和可重建缓存。会话、用户配置、凭据文件、Electron 用户配置与数据目录注册值保留，便于重装恢复；卸载不删除用户数据目录。
6. 项目本身、项目级 `.agents` / `.567agent` 数据、用户共享的 `%USERPROFILE%\.agents\skills`、Windows 下载目录和 Windows 凭据存储仍由用户或系统管理，不会被安装器移动。项目路径可自行位于任意磁盘；其存储位置不依赖应用数据目录。

## 备选方案

- 只新增程序安装目录选择：不能迁移会话和配置，无法解决系统盘数据占用。
- 仅设置环境变量：Electron 启动方式、文件关联启动与系统启动任务可能绕过环境变量，且安装器无法可靠迁移自动更新目录。
- 用 NTFS junction 映射旧位置：路径透明，但卸载、磁盘断开和复制回滚更难验证，也会让用户看到路径与实际存储位置不一致。

## 验证

纯数据布局和启动器环境注入有回归测试；安装器脚本合同覆盖选择页、目标目录和保留源数据的迁移方式；Windows 启动器按 Windows x64 交叉编译。最终安装/升级/迁移体验仍需 Windows 实机验证，尤其是大数据目录复制耗时、磁盘权限和自动更新多版本切换。
