# ADR 0139: 手机账号凭据与派生模型授权的恢复边界

状态：2026-10-23 本地候选，未发布。

## 背景

更新后仍可恢复用户资料和模型目录，但旧模型密钥被拒绝时没有恢复路径。授权管理接口绕过账号续期，失败后还会把账号访问令牌作为模型密钥返回；启动资料验证失败被缓存资料掩盖。这些是已复现的客户端缺口，不代表已经证明所有历史用户反馈均由同一原因导致。

## 决策

- 账号 REST 请求统一识别明确鉴权拒绝，包括 New API 的失败信封；继续复用 TokenRefresher 的并发去重、退避、Cookie 续期与已有账号恢复流程。429、5xx、网络错误和普通权限错误不触发重新发送保存密码或清理登录。
- 将分组密钥解析、持久缓存、并发与自建令牌台账收敛到 GroupApiCredentials。请求列表、读取完整密钥、创建和重读均经过账号恢复；管理请求失败直接报告，不再以账号令牌代替模型密钥。
- 缓存保持现有服务身份和账号令牌命名空间。明确的模型 HTTP 401 可使本地缓存失效，并在本次操作中最多修复一次。不会删除用户密钥来修复缓存，也不会重放已输出内容或已被模型接受的回合。
- 显式登录或退出推进会话代次；迟到的授权管理响应不能缓存密钥或以新账号继续旧请求。现有已保存缓存格式兼容，不要求用户清数据或退出再登录。
- 启动先显示缓存页面，再后台验证资料。无法验证时显示缓存提示与重试入口；临时故障保留会话。无法自动恢复的明确账号拒绝提示重新验证。

## 备选与后果

强制更新后登出会迫使所有用户重新登录，无法解决后续密钥失效，因此不采用。每次聊天都重新创建密钥会积累服务端令牌，也不采用。只在收到明确拒绝后修复，成功请求没有额外模型调用；修复管理请求可能增加少量网络等待。

## 验证

本机 HTTP fixture 覆盖持久缓存恢复后密钥被撤销、账号失败信封续期、管理接口暂不可用、普通模型权限失败、账号切换竞态；AppViewModel 流程覆盖缓存资料验证失败后保留身份、恢复网络并重新验证。测试不使用真实账号或付费模型。
