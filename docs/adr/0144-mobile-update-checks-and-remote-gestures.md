# ADR 0144：手机更新提示与远控手势归属

- 状态：已采纳
- 日期：2026-10-25

## 背景

更新检查原先由关于页局部状态持有，只能手动触发。远控把单指滚动作为独立模式，用户必须在光标操作和滚动之间切换。桌面画布曾由默认导航和旧迁移自动置顶。

## 决策

- AppUpdateController 统一自动与手动检查，状态由 ViewModel 暴露。启动、前台恢复和主页切换调用同一自动检查；6 小时节流落盘，手动可重试，失败安静处理。已发现版本与其对应的当前版本一起缓存，升级后重新检查，避免把旧结果跨应用版本复用。每个版本的自动提示去重，关闭后保留关于页标记。
- 不增加后台下载或安装。测试包不能从提示直接下载正式包；打开发布页由用户选取相同包名和签名。正式包保持原下载线路。没有把任意远端 APK 宣称为经过签名验证的升级包。
- RemoteTouchLayer 继续唯一拥有触摸序列。双指动作累积至阈值后锁为滚动或缩放；第三指用于本地画面平移。第二指加入时立即释放已有拖拽，该接触序列剩余手指不产生远程点击。取消、旋转、切模式继续释放按键。
- 直接触控继续使用既有归一化绝对坐标及同一 aspect-fit/缩放映射。触控板在相对坐标宿主发送原相对增量，在绝对坐标宿主维护连接范围内虚拟光标。不改输入协议，不扩大 inputEnabled 授权。相对坐标宿主（包括当前 Wayland 适配器）明确禁用直接触控，因为它没有能与当前共享画面可靠对应的绝对定位合同。
- 桌面导航版本 3 只把画布一次性移入更多，保留其他布局与数据；之后用户重新置顶仍生效。新安装不默认置顶画布。生图仍打开图片历史面板，不自动调起画布。
- 新会话不再读取内置装饰/纹理偏好进行绘制，保留旧存储和主题扩展合同。工作/编程仍分别决定新会话的任务指导与叙事模式，界面用办公任务/编程开发表明用途，不修改模型选择。

## 替代方案与后果

没有在各页面重复建立自动检查器；没有将新旧 APK 自动交给包管理器。没有用估计坐标在 Wayland 上冒充直接点按，也未将独立屏幕捕获与输入会话强行绑定。代价是相对坐标宿主暂不支持直接触控；真实系统授权、跨设备网络与安装签名仍须真机验证。更新偏好只保存版本和检查时间，不保存账号或聊天数据。
