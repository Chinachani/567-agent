# ADR-0125：设计分享包使用 `.567design` 扩展名

## 状态

已采纳（2026-10-02）

## 背景

设计画布的工作态是 `.vetd/` 目录，分享包是单文件 ZIP。此前分享包扩展名为 `.vetdz`，仅应用内导入器能够识别；用户无法从文件名直观辨认格式，桌面系统也没有对应的文件类型关联。

## 决策

- 新导出的分享包使用 `.567design`，导入选择器和拖放入口使用新扩展名。
- 注册桌面文件类型，并让双击操作在 567 Agent 的分享包预览器中打开文件。
- `.vetdz` 和历史 `.vetd` ZIP 继续可导入；工作态 `.vetd/` 目录格式不变。
- 文件类型图标复用 567 Agent 应用图标，Windows 显示名称为「567 Agent 设计分享包」。

## 后果

- `.567design` 分享包的完整打开流程依赖安装版的文件类型注册；Windows Inno Setup 与 macOS 应用文档类型均进行注册。
- 旧分享文件不需要重命名或重新导出。
- Linux 桌面文件类型关联暂由桌面环境按通用压缩文档处理；应用内画廊导入仍支持所有兼容扩展名。
