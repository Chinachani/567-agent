# ADR-0151：当前电脑会话接力与手机后台任务提醒

状态：已实现
日期：2026-11-01

## 背景与备选

手机只能从电脑会话列表找目标，主进程原本没有 Renderer 当前查看的会话事实。用运行列表第一项推测当前会话会接错任务；信任 Renderer 提交的标题或文件路径会扩大远程边界。后台提醒若观察 UI 历史快照，会把恢复历史、切页与重新连接误判为新任务。

## 决定

- 可信主窗口只上报当前查看的普通会话 Runtime ID，离开会话页即清除。Main 从现有用户会话目录解析公开会话 ID 与标题，从 Runtime 与交互 Broker 投影运行、等待、失败状态；不保存第二份历史或执行状态。异步解析按导航代次丢弃过期结果，目录变化重新解析标题。
- 已配对远控链路的 `device.status` 帧追加可选 `activeConversation`，有变化时发送（最多每秒一次），既有诊断快照供首次连接与每五秒补偿。字段只包含公开 ID、标题与状态，不传 Runtime ID、路径、正文。旧端缺字段继续使用会话列表，新端断线清除当前入口。点击接力绑定明确的设备与会话，复用既有本地镜像与远程打开流程。
- 手机提醒由独立策略读取真实在途回合事件，前台不发；后台的提问、异常中断、持续至少 30 秒的任务完成或绘图完成才发。同回合、同请求与终态去重；已打开电脑会话也观察实时状态跃迁，首次与重连快照只建基线。每个会话使用稳定通知标识替换，避免重复轰炸。用户主动停止不发异常提醒。
- Android 用独立通知通道和本地 PendingIntent。前台首次发送任务或接力时请求系统通知权限，拒绝后不反复弹。通知只显示通用状态，不带正文或原始报错；点击携带本地会话 ID，待启动恢复完成并验证会话存在后打开。无新后台服务、推送通道或模型重试，系统杀进程或限制后台时不承诺送达。
- 代码块通过可选 MarkdownHost 能力使用现有原生另存为与内存只读预览。新内存预览展示源码，不自动执行生成的 HTML/JavaScript，也不创建临时用户文件。旧宿主缺能力时仍显示复制。

## 兼容与验证

不迁移或重写历史、模型、协议、线路与草稿，不改变远控授权及模型执行边界。编辑较早的桌面消息仅在提交时沿既有分支导航合同创建新分支，后续历史保留；最后一条消息继续沿用既有替换语义。验证覆盖浏览器打包边界、改键与作用域、代码/表格操作、编辑分支、可信 IPC、选择竞态、旧协议兼容、接力设备身份、后台去重与消息编辑交互。
