# ADR 0146: 按模型选择 OpenAI 推理协议

- 状态：已采纳
- 日期：2026-10-26

## 背景

567 网关里的 Codex 型号应默认通过 Responses 调用，其他分组仍可能只支持 Chat Completions。仅替换 URL 会破坏消息、工具与流事件解析；全局切换还会影响 Gemini、Claude 等兼容型号。用户需要在现有模型参数入口覆盖协议，刷新目录和重启后继续生效。

## 决策

桌面受管且属于可信线路的模型，在型号或分组包含独立 Codex 标识且没有显式模型 API 时，默认 `openai-responses`；其他型号沿用原模型或服务商协议。第三方私有服务商不受受管默认策略影响。用户在模型配置的“模型参数”中选择自动、Responses 或 Chat Completions。

手动值复用 `modelOverrides[modelId].api`，通用 Coding Agent 正式校验并在注册表合并时应用该字段。自动模式移除覆盖。桌面专用 IPC 校验两种协议或 null，由现有模型设置服务锁内读改写；整份旧设置回写不能覆盖最新协议选择。分组对账不再强制改回 Chat Completions。已解析并在执行中的 model 不随设置变化，下一次解析使用新协议。

手机直连使用同样的 Codex 默认识别规则，手动值复用现有模型参数命名空间，以服务身份、分组、型号和 `api` 类型隔离，不写入会话迁移备份。现有上下文管理面板增加协议入口；电脑会话不提供手机本地协议覆盖。每次 flow 开始固定有效协议。

桌面使用已有公开 Responses Provider（API key 网关协议，并非 ChatGPT OAuth Codex 协议）。手机新增独立的 Responses 请求编码与 SSE 解析，使用 `input`、扁平函数工具、`store:false` 和明确终态。历史沿 SDK 的 EasyInputMessage 形态保留角色与图片；不依赖服务端保存的 response_id。encrypted reasoning 不展示、不记录到用户正文。图像生成服务的独立接口不在本次迁移范围。

手机工具调用仅在成功 completed 终态且参数完整时释放一次；失败、截断、空响应及 incomplete 不执行工具。流事件、工具数量与参数设置上限，保留 usage、refusal、取消和连接重试边界。桌面动态签名仍在每次 HTTP 尝试前生成，协议设置不保存签名头。

## 备选方案

- 全局切换：会影响尚不支持 Responses 的分组，拒绝。
- 只改 URL：请求体和流事件不兼容，拒绝。
- 新建协议配置文件：造成模型参数第二事实源，拒绝。
- 失败后自动回退并重发：可能重复计费或执行工具，拒绝。由用户明确修改协议并决定是否重试。

## 后果与兼容

已有明确模型 API 优先保留；默认策略仅补齐缺失值。目录刷新保留手动 override。手动协议取决于服务商实际支持，客户端不做付费兼容性探测；未真实调用第三方服务验证能力。旧客户端不消费新增覆盖字段，跨版本降级不保证执行手动协议选择。当前请求不会因切换设置而自动重发。所有测试使用隔离配置、本地 HTTP fixture 或注入传输，不读取真实账号状态。
