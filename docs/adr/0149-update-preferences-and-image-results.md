# ADR-0149：更新偏好、说明历史与手机图片结果证据

状态：已实现，待用户验证
日期：2026-10-30

## 背景与决定

用户需要更清楚地了解更新内容和下载进度，并报告队列遮挡任务状态、表格网址错误、手机绘图未得到图片却显示完成及工具详情重复。

1. 复用 UpdaterService、既有下载源及重启确认。新增自动检查、间隔、自动下载与提醒偏好，经既有配置读改写入口保存；写盘失败保留原值。手动检查在下载、已准备及安装中不重置状态。
2. 历史说明独立读取固定官方 GitHub Releases API，限响应大小、超时与正式记录，内存短时缓存并合并并发请求。说明请求不控制安装包；记录实际运行版本用于上次更新范围。首次使用不捏造过去版本。
3. 队列和权限抽屉回归输入区正常文档流，与任务条和输入框按顺序占位。保留主题替换和展开、删除、立即发送、重排能力，内容过长时局部滚动。
4. GFM 表格自动链接没有子节点位置时，只对整单元格的重复同一 HTTP(S) 目标形态恢复；代码、显式目标和结构化标注不变。
5. 手机专用图片模型的参考图通过 multipart images/edits 发送；Gemini 保持多模态 chat 请求。一次绘图先确定一种协议，无图片或错误不再静默切换协议重发。保留既有分组凭据恢复。
6. 图片输出仅认可协议图片字段和 Markdown 图片；普通正文下载链接不算证据。验证图片字节签名、体积并保存实际 MIME；取图失败持久化 error，保留用量和其他回复，不由后续 Done 改成成功。工具 result 与相同 detail 只渲染一次。

深度复核补充：更新服务按检查与下载身份丢弃取消后的回调，退出后不再安排新工作；唤醒遵守用户检查间隔。更新引擎在同步启动错误与 macOS 准备阶段取消时完成 Promise 并释放监听。交付索引向 Markdown 修复插件传入同一原文。图片传输与持久化共用 12 MB 上限，参考图按实际 MIME 发送，结果解析保留首个图片字段并跳过空值。

## 兼容与限制

不改变聊天历史格式或账户数据。旧图片未返回或未保存时，无法从文字下载说明恢复像素。只验证本地协议夹具，不用真实付费图片请求。图片格式签名检查不代替最终解码器。

不新增强制自动重启、预发布下载渠道或新的镜像服务；既有安装器在正常退出时的应用更新行为保留。手机自动检查更新机制独立，本次只修手机绘图。

## 验证

按服务、IPC/preload、真实组件、会话持久化及隔离 Electron 布局分别回归；结果见交付记录。手机仪器测试已编译，设备执行需要测试设备。

## 请求合同参考

图片编辑字段已对照 [OpenAI 官方 images/edits 说明](https://developers.openai.com/api/reference/resources/images/methods/edit)，保留用户所选模型，不替换型号。第三方网关的实际支持需要用户在真机测试；本轮无真实计费请求。
