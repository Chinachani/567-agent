# ADR 0137: 567 存储写入、旧数据读取与 Windows 启动目录

状态：2026-10-21 本地候选，等待备案后发布。补充 ADR 0130/0136；不迁移正在运行的生产实例。

## 背景

品牌替换后，手机 Settings、桌面默认会话及批处理仍有旧名字的当前写入。直接替换字符串会使旧历史和登录状态不可见。Windows 只有 launcher 注入数据根，直接运行版本 EXE 会在状态和更新目录之间分叉。

## 决策

- 新项目状态、会话和批处理写 `.567agent`；旧 `.vetta` 会话原位兼容并集列举，保留路径引用。元数据按文件读取：存在的 canonical 文件是事实源，仅 ENOENT 才回退旧文件。错误或损坏不能从旧文件恢复过期状态。
- 手机使用类型保持的 Settings 适配器，将 `agent567.*` 的旧 `vetta.*` 值惰性读取到新键。新键优先；写入和删除清理相应旧键，退出登录和删除会话不能复活旧值。共享同步锁覆盖读取迁移、写入和删除。
- 567 数据根环境变量仍是 `AGENT567_HOME`。Windows 环境未由 launcher 填充时，在任何绑定目录的模块求值前读取 HKCU/Software/567Agent/DataRoot，初始化用户数据和更新目录。注册表查询失败或选中磁盘不可用时停止，禁止悄悄选空默认根。
- 后台安装不修改已登记根；显式安装可在确认后重新关联有初始化标记的现存目录，不合并不同目录。静默重新关联必须显式声明。回滚重命名失败保留两个现场并明确报告位置。
- 旧插件 slug、SDK/npm 别名、远控线协议、历史扩展名和安装器参数属于兼容 ABI；上游版权、来源链接保留。它们不构成当前上游服务依赖。退役的专用内置 MCP 不再自动注入，用户配置的 MCP 不变。
- 共享 MCP 默认项目文件为 `.567agent/mcp.json`；只有该文件缺位时读取旧 `.vetta/mcp.json`，不覆盖或迁走来源。空配置、损坏配置及权限错误不恢复旧服务；显式自定义项目目录不触发旧路径查找。

## 备选方案与影响

没有批量改写旧 journal 路径、合并非空数据目录或机械删除兼容标识；这些会破坏历史、签名或旧客户端升级。选择边界适配和新写入路径，允许逐项验证，保护回退资料。

本次源码检查和两端构建不等于 Windows 原生安装验收。原生矩阵增加无 launcher 环境的后台更新及恢复旧目录；需在一次性 Windows runner 验证后才发布。充值保持关闭，支付补丁仅在本地隔离候选完成演练。
