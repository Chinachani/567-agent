# 手机端连接与模型排障

手机端「直接对话」通过 HTTPS 连接 567 API；连接 Desktop 的远程会话是另一条通道。本页用于区分并排查这两类问题。

## 直接对话无法加载模型

依次检查：

1. 确认手机可以访问互联网，并在「我的」页面确认 567 API 登录仍然有效；必要时重新登录。
2. 返回对话页，确认已选择可用的分组，再打开模型选择器刷新模型列表。
3. 确认账号仍有调用权限和可用额度；如果只有一个模型或一个分组报错，可切换到其他已开放模型验证。
4. 暂时切换 Wi-Fi 与移动网络。如果使用 VPN、系统代理或拦截 DNS 的工具，检查它是否阻断 `api.567.wiki` 的 HTTPS 请求。
5. 如果连接错误发生在请求刚开始，客户端会对首次建连超时自动重试一次。流式响应已经开始后若连接中断，客户端不会自动重发；先检查当前会话是否已有回复，再决定是否手动重试，避免重复执行请求。

如果模型目录仍无法加载，记录应用版本、所选分组、发生时间、网络类型和界面显示的错误信息，再向维护者反馈。请勿发送密码、Token、Cookie、API Key 或聊天备份文件。

## 无法连接 Desktop

Desktop 远程控制和手机直接对话相互独立。若只有远程连接失败：

- 确认 Desktop 正在运行，手机与 Desktop 使用同一配对邀请；重新配对后旧邀请需要重新生成。
- 局域网邀请使用 WSS，并固定 Desktop 证书指纹。更换 Desktop 证书后应重新生成邀请并重新扫描，不要手工把地址改成 `ws://`。
- 远程桌面画面、权限和中继问题请按 [远程桌面黑屏诊断](./remote-desktop-debugging.md) 排查；首次真机设置见[真机测试操作手册](./remote-desktop-real-device-testing.md)。
