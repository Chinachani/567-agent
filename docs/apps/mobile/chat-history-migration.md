# Android 聊天记录迁移

如果旧版 Android 应用由旧签名密钥签名，换用新签名的正式版前需要通过迁移 APK 导出聊天记录。Android 不允许不同签名的 APK 直接覆盖安装；迁移备份可在卸载旧应用后保留会话。

## 迁移步骤

1. 从项目维护者提供的官方渠道取得迁移版 APK，并安装到现有旧版之上。迁移版使用旧签名，因此可以覆盖旧版。
2. 打开迁移版，进入「我的 → 数据 → 导出聊天记录」。设置并确认一个 **8 到 128 个字符**的备份密码，然后在系统文件选择器中保存 `.567agent-backup` 文件。
3. 确认备份文件保存到了下载目录或其他卸载应用后仍保留的位置。备份文件最多 50 MB；备份包含本地会话和消息内容，不包含登录凭据。
4. 记好备份密码。卸载迁移版，再安装使用新签名的正式版。由于签名已更换，必须先卸载旧应用，无法直接覆盖安装。
5. 打开正式版并重新登录，进入「我的 → 数据 → 导入聊天记录」，选择备份文件并输入原密码。
6. 打开几个会话确认内容已恢复后，再决定是否删除备份文件。

## 导入规则与限制

- 导入会把备份中尚不存在的会话加入当前设备；若会话 ID 已存在，该会话会被跳过，不会覆盖或合并已有会话内容。
- 账号密码、访问令牌、API Key 和远程配对凭据不会写入备份。迁移后需要重新登录并重新配对远程桌面。
- 单个备份的导入和导出上限为 50 MB。聊天图片在设备上以应用私有文件保存，迁移导出时会将图片连同消息写入加密备份；备份文件经过密码加密，请勿上传到公开网盘或工单。
- 应用不保存备份密码。忘记密码后无法解密备份；请在确认新设备内容完整前保留原文件和密码。
- 新版导出文件使用 `.567agent-backup` 扩展名；导入仍兼容旧版 `.vetta-backup` 文件。
- 不要把备份保存在应用私有目录中，否则卸载应用时备份可能一起删除。

## 常见问题

### 旧版无法安装迁移 APK

确认迁移 APK 来自官方渠道，并且是为旧签名迁移准备的版本。不要先卸载旧版；卸载会删除尚未导出的应用私有聊天数据。

### 正式版提示签名不一致

先确认迁移备份文件已保存到应用之外，再卸载旧签名应用并安装正式版。直接覆盖安装会被 Android 拒绝。

### 导入后没看到部分会话

如果当前设备已有相同 ID 的会话，导入会跳过备份中的对应会话。检查目标会话列表并保留备份文件，避免在未核对前删除原始记录。

### 密码正确但文件无法导入

确认选择的是完整的 `.567agent-backup` 或旧版 `.vetta-backup` 文件，密码与导出时一致，文件大小不超过 50 MB，且文件没有被同步工具截断或修改。
