# 工作区依赖覆盖说明

## `@peculiar/asn1-schema = 2.10.0`

证书生成链的 `@peculiar/x509` 接受 `^2.6.0`，而锁定的 `@peculiar/asn1-x509`、`asn1-cms` 等 ASN.1 包要求 `^2.10.0`。工作区统一使用 2.10.0，避免同一证书对象经过不同版本的装饰器 Schema 注册表。此覆盖属于证书链依赖的一致性约束，不是安全漏洞修复声明。

修改时同时检查 `bun.lock` 中全部 `@peculiar/asn1-*` 依赖、运行桌面证书与配对定向测试，以及完整 `bun run check`。只有证书链可以自然收敛到单一兼容版本后才删除覆盖；不能为通过类型检查回退证书功能。
