# 567 Agent：1.x 待发布变更

整理日期：2026-10-13。基于已发布的 1.2.10；正式发布时再确定下一个 1.x 补丁版本和标签。

## 新增与改进

- 桌面「设置 → 通用」可选择更新下载来源：GitHub 官方源（默认）或 GitHub 加速代理（gh-proxy.com），重启应用后生效。加速代理是可选的第三方服务，速度和可用性取决于网络环境；失败时可切回官方源。
- 桌面和 Android 在回答结束后保留本次处理总耗时。新记录的耗时会随消息保存，重新进入会话仍可查看；历史上没有保存耗时的旧回答不会补造数据。总耗时包括生成和工具执行的等待时间，不是模型 Token 统计。
- 风格库封面按可见区域加载，并限制同时下载的数量；GitHub 原始文件读取失败时尝试同一风格库的 CDN 镜像。成功封面保存到本机，离线重新打开也可使用缓存；失败结果不会永久缓存。
- 修复紧凑风格色板的预览背景、文字和边框缺失；风格库顶部统计改为风格数量，项目页继续统计项目数量。
- 移除前往 567 API 官网、控制台、找回密码、API 文档和网页版订阅管理的按钮。登录、模型调用与应用内充值保留现有服务接口。
- 本地自定义模型供应商列表隐藏应用托管的 567 API 条目，减少与账号模型目录的混淆。

## 版本范围

上述改动属于当前 1.x 产品维护。LiteLLM 的 2.0 方案仅完成文档和现有代码依赖评估，尚未切换客户端服务地址或生产后端。
