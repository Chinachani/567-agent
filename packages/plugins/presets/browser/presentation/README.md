## 适合什么任务

Browser Use 面向必须在真实网页里完成的工作，例如登录后台、翻页查数据、填写表单、切换筛选条件，或把多个页面的结果整理到一起。仅需要公开资料摘要时，优先使用网页搜索；需要“进入页面并把事情办完”时再使用浏览器操作。

## 使用方式

直接在对话中说明目标、网址和不能越过的边界。遇到登录、验证码或二次验证时，Agent 会把可见浏览器窗口交给你处理，完成后继续任务。涉及发布、付款、删除或最终提交时，建议明确要求停在确认前。

默认优先连接你当前已打开的浏览器，先确认目标标签页；首次连接可能需要你在浏览器里开启本地远程调试并授权。连接失败会说明原因，不会静默另开窗口。只有你明确要求独立任务浏览器时，才创建新窗口。

首次使用时，Agent 会检查并在 567 Agent 的私有 npm 目录中自动安装锁定的 `agent-browser` 运行时。需要独立任务浏览器且系统没有可复用的 Chrome 时，才按健康检查安装 Chrome for Testing。运行时由 567 Agent 单独管理，不会覆盖机器上的全局安装；自动安装失败时可在插件面板中重试和诊断。

## 会话与隐私

每个任务使用独立的控制 session 并绑定目标标签页。连接当前浏览器会共享它的登录状态，控制 session 不等于隔离 profile。任务结束保留你的浏览器与标签页；独立任务浏览器可按 profile 和账号键分别保存登录状态。

普通表单使用页面元素定位；画布等区域可用视口截图与页面坐标操作，并检查结果。这不是整个桌面的鼠标控制，也不能用来操作系统弹窗。不要把邮箱、密码、Cookie 或 token 写进 profile 名称、提示词或日志。
