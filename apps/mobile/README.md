# 567 Agent Android

Android 客户端提供两种对话方式：连接 567 Agent 继续桌面会话，或在手机上通过 567 API 直接对话。远程桌面预览可查看画面并发送输入；它与手机端直接对话使用不同的连接配置。

会话列表按设备来源分区。手机端可按需读取已连接 Desktop 的会话目录；打开某条 Desktop 会话后，才从电脑拉取消息历史并在手机本地缓存。同步方向是 Desktop 到手机，Desktop 不读取手机端会话。

手机端默认会在云端对话结束后生成最多三条后续提问建议，可在「我的 → 设置 → 使用体验 → 预测下一句」关闭。远程桌面首次显示画面时，Desktop 会要求本机用户确认并选择要共享的屏幕或窗口；取消或系统未提供屏幕来源时，手机会显示对应状态。

## 用户指南

- 欢迎页及「我的 → 功能指南」可随时查看手机直连、电脑会话、远控、附件和账号排查步骤。恢复缓存后会在后台验证登录；暂时无法验证时会说明缓存状态并提供重新验证。失效的派生模型密钥收到 HTTP 401 时可自动重取一次，已输出的回合不会自动重发。

- 登录页和「我的」自动从主站 `api.567.wiki` 获取线路列表，可手动刷新、选择和检测接口连通性。获取失败继续使用已保存列表及内置兜底，列表更新不会自动切换当前线路。新安装默认德国；升级会将无主动选择记录的旧版自动大陆默认迁到德国，保留明确选择、旧版手工服务器配置和自定义地址；手机直连与电脑各自保存选择。切换保留登录和模型容量，当前任务继续使用原线路，不自动重发请求。手机远程会话在模型列表中显示电脑线路，由电脑管理。

- 文件链接列表超过 3 个时默认收起为产物摘要；少量文件直接显示。展开后保留完整文件名，超过 5 个提供“查看全部”抽屉；可查看和复制对应设备的文件路径，原始消息内容仍完整保存。

- Markdown 表格保持行列布局和表头，单元格内自动换行；宽表可左右滑动查看，长内容不会以省略号截断。手机 API、电脑会话和工具详情使用相同的表格显示方式。
- 等待首字时显示「等待模型回复」。手机 API 会话断网后保留已发送消息与部分回复，并释放发送状态；恢复网络后可重试或继续发送，客户端不会自动重复提交已经可能送达的请求。
- 远程电脑会话断网时显示「正在恢复连接」，两端更新后可按原任务标识恢复文字、工具记录和待回答问题，不重新执行任务。电脑重启、恢复记录已清理或旧版电脑不支持时，会提示先检查电脑记录；一次重连等待最多 90 秒。
- 「我的」顶部个人信息进入账号页，可修改昵称、刷新资料以及登录/退出。用户名只读；昵称、密码与邮箱在应用内修改，改密需要当前密码，绑定邮箱需要邮箱验证码。退出时可选择保留手机记录；登录成功后先显示账号，模型目录在后台刷新。
- 工作台的图片附件提供列表缩略图，缺失或过大的原文件仍可查看详情；远程缩略图按可见范围加载。
- 设备页提供只读桌面预览，进入全屏后可操作与输入。全屏隐藏系统状态栏，操控栏覆盖在画面上并可收起；说明和统计按需弹出，输入栏支持软键盘及 Esc、Tab、方向键和 Ctrl 组合键；切换全屏保留当前连接。进入全屏自动横屏，退出恢复原屏幕方向；直接触控时单指点击/拖拽画面位置；触控板时单指移动光标、轻点点击。两种方式均支持双指同向滑动滚动电脑页面、捏合缩放、三指平移本地画面，“适应屏幕”可复位。只支持相对鼠标的电脑会明确禁用直接触控。Wayland 电脑使用触控板：单指滑动移动光标，按住再滑动拖拽；需要在电脑开启远程输入并同意系统授权。开启自动共享后，手机重连复用仍有效的屏幕会话；退出电脑程序或系统撤销授权后可能需要重新选屏。
- 会话右上角「上下文管理」可查看占用、压缩历史及开始新上下文。手机直接调用 API 的摘要和起点随会话保存，聊天记录仍完整可查看；默认达到模型容量约 80% 时自动压缩，容量未知时可手动操作。压缩会使用当前模型和分组，产生模型用量。手机占用为估算值。手动压缩至少需要两轮有效对话、保留最近一轮；自动压缩仍优先保留最近三轮，摘要未减少占用时会保留原上下文并提示。
- 电脑会话的上下文由电脑维护，手机上的压缩和自动压缩开关通过新协议交给电脑执行，需要两端更新。电脑自动压缩开关仅覆盖当前运行会话，重启后恢复电脑设置；开始新上下文会新建电脑会话，保留旧会话。
- [聊天记录迁移](../../docs/apps/mobile/chat-history-migration.md)：签名更换、重装前导出和导入本地会话。
- 输入草稿按账号和会话保存在本机，图片与文档附件存入应用私有文件。切换会话或重建进程后可恢复，发送成功后清除对应草稿；草稿不包含在聊天迁移备份中。未确认账号身份时明确提示暂存，并在验证后保存。
- 聊天附件图片保存在应用私有文件中，消息记录只保存附件引用；迁移备份仍会把图片包含在加密文件里。
- [手机端连接与模型排障](../../docs/apps/mobile/chat-connection-troubleshooting.md)：检查登录、模型目录和聊天连接问题。
- [Mobile 文档索引](../../docs/apps/mobile/README.md)：远程桌面开发、真机测试和排障资料。

## 手机界面

手机界面使用统一的中性色工作空间：主页集中展示新建入口、连接设备与最近会话；会话列表可搜索、筛选，并在有历史记录时直接新建；对话模型用金色、生图模型用紫色区分。聊天输入区将文字编辑与附件、发送操作分开，触控按钮保留至少 48dp。账号页将余额与操作分行，功能指南按主题展开为分步说明。

主题、卡片、列表、输入和导航来自 `ui/theme` 与 `ui/components`。Android Studio 可打开 `shared/src/androidMain/kotlin/org/agent567/android/ui/preview/MobileWorkspacePreviews.kt`，查看七个真实生产页面在小屏、深色、大字体与横屏下的预览；预览只使用内存样例和空回调，不创建账号或网络客户端。真实界面操作回归位于 `androidDeviceTest/ui/MobileWorkspaceRedesignTest.kt`，截图夹具位于 `MobileWorkspaceScreenshotTest.kt`。

## 开发

这是 Kotlin Multiplatform 项目。共享 Compose UI、业务逻辑和数据层位于 `shared/src/commonMain`；Android 专属实现位于 `shared/src/androidMain`；应用入口位于 `androidApp`。

在 `apps/mobile` 目录运行：

```bash
./gradlew :androidApp:assembleDebug
./gradlew :androidApp:assembleDebugTest
./gradlew :shared:testAndroidHostTest
```

`assembleDebugTest` 会生成可与正式应用并行安装的测试版（包名 `com.api567.agent.test`）。

连接已启动的 Android 设备或模拟器运行仪器测试：

```bash
./gradlew :shared:connectedAndroidDeviceTest
```

## APK 签名

发布签名材料不能存放在仓库。构建正式版前，通过本机环境变量或用户级 `~/.gradle/gradle.properties` 配置：

- `AGENT567_ANDROID_KEYSTORE_PATH`
- `AGENT567_ANDROID_KEYSTORE_PASSWORD`
- `AGENT567_ANDROID_KEY_ALIAS`
- `AGENT567_ANDROID_KEY_PASSWORD`

Local release builds and GitHub Actions use `AGENT567_ANDROID_*` signing variables.

不要把密码写入仓库中的 `gradle.properties`。Debug 构建使用 Android 标准 debug 密钥。

签名迁移期间使用单独的 legacy 密钥构建过渡 APK：

```bash
./gradlew :androidApp:assembleMigration
```

过渡版配置使用 `AGENT567_ANDROID_MIGRATION_KEYSTORE_PATH`、`AGENT567_ANDROID_MIGRATION_KEYSTORE_PASSWORD`、`AGENT567_ANDROID_MIGRATION_KEY_ALIAS` 和 `AGENT567_ANDROID_MIGRATION_KEY_PASSWORD`。密钥必须保存在仓库之外；迁移密钥仅用于过渡 APK，正式版必须使用新的发布密钥。用户操作步骤见[聊天记录迁移指南](../../docs/apps/mobile/chat-history-migration.md)。

## 自动更新提示

应用启动和回到前台时会后台检查 GitHub 最新发布，自动检查间隔至少 6 小时；失败不弹窗，可在「关于」手动重试。每个新版本自动提示一次，「我的 → 关于」保留新版本标记。应用不会自动下载安装。正式包可在关于页启动应用内后台下载，显示进度并支持暂停/继续，最多两连接；不支持范围时单连接，重开进程后手动继续。通知权限被拒绝不阻止用户发起的下载，但系统可能不显示通知。下载完成后验证官方 SHA-256、包名、版本和当前签名，安装需授权来源并手动确认；缺少校验信息时打开发布页。测试包从提示进入发布页核对包名和签名，正式包仍可使用已选择的下载线路。

### 调用协议

直连对话的上下文管理提供调用协议设置：自动、Responses、Chat Completions。自动模式下 Codex 型号或分组使用 Responses，其他型号使用 Chat Completions。选择按服务、分组和型号保存，后续请求生效；不支持的协议会报错，不会静默换协议重发。电脑会话的协议请在电脑端模型参数中修改。图片生成服务接口独立于对话协议。

## 绘图结果

手机专用绘图模型携带参考图时使用图片编辑接口，Gemini 使用多模态对话接口。一次操作不因无图片或接口错误自动换协议重发。只有取得有效图片数据后才显示完成；纯文字下载说明不视为图片，失败状态及已收到的用量随历史保存。旧回复中未返回或未保存的图片不能凭文字恢复。
