## Model calls per run

Under **Settings → Agent → Task execution**, enable or disable the model-call budget and choose its maximum count. The default is enabled with 100 calls. One task may request the model many times, including after tools return results; this is separate from token context capacity.

Turning the limit off retains the last count. Saved changes apply to the next run; a run already in progress keeps its original budget. **Adjust call limit** on a budget error opens this setting directly. Sending “continue” in the same chat starts a new run using the existing history.

With this budget disabled, manual stop, tool-call limits and error-recovery limits still apply. Longer tasks may use more model quota. Remote chats on a phone follow the connected computer’s setting; direct mobile API chat has no corresponding Agent-loop setting.

Before exporting diagnostics, remove credentials, cookies, pairing data, webhook URLs, and private project contents.

## Sidebar style

In **Settings → Appearance → Sidebar Style**, choose **Classic** or **Floating**. Both the workspace sidebar and the settings navigation update immediately. Classic uses a flush edge with a right-hand divider; Floating adds outer spacing, rounded corners, and a border. In narrow windows, settings navigation remains a scrollable icon rail. Changing the style preserves the current settings page and unsaved input.

## Interface scale

In **Settings → Appearance → Interface size**, choose 75%, 90%, 100%, 110%, 125%, or 150%. Drag to preview a step and release to save and apply it. You can also click a step or use the arrow keys. **Reset to default** returns to 100%. A failed save leaves the effective scale unchanged and shows an error.

The defaults are `Ctrl/Cmd+=` to zoom in, `Ctrl/Cmd+-` to zoom out, and `Ctrl/Cmd+0` to reset. These bindings are configurable in Shortcuts. The setting persists across restarts and applies to the main window; auxiliary windows and embedded browser content retain their own scale.
