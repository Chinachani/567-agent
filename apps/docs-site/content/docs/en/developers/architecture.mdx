567 Agent uses a monorepo for the desktop application, hosts, and core TypeScript packages. The dependency direction is:

```text
applications → runtime-* → coding-agent → agent → ai
```

## Core packages

## Runtime packages

The runtime layer organizes Coding Agent capabilities into reusable session, storage, tool, MCP, and telemetry interfaces for desktop hosts. Runtime packages must not depend on a particular desktop UI.

## Application layer

The desktop application owns the Electron lifecycle, native capabilities, IPC, and user interface. Business APIs own accounts, organizations, model provider configuration, and other server-side rules.

<Callout type="info" title="Boundary constraint">
  Core libraries must not depend on the desktop application or administration console. When adding a capability, first decide whether its contract belongs to the core, runtime, or host layer; do not move UI lifecycle concerns into a lower-level package.
</Callout>
