模型配置决定普通会话、知识库加工、批量任务、自动化和 Claw 等路径可用的模型。入口：**设置 → 模型配置**。

配置文件路径：`~/.567agent/agent/models.json`（开发隔离环境可能使用 `AGENT567_CONFIG_DIR` 指向的目录）。

## 按来源配置

模型配置分为 **567 API**、**预设服务商**、**本地服务商** 三个标签页。567 API 用于管理专属分组和线路；预设服务商用于启用内置目录中的服务；本地服务商用于管理自己添加的服务，包括 Ollama 和自定义远程端点。

每个标签页下方都有独立的 **模型参数** 区域，只列出该来源已接入的模型，可设置调用协议和上下文容量。同名模型按服务商区分。在模型配置页内切换标签会保留各页的模型选择、搜索和未保存草稿；未接入模型时会显示对应的接入提示。

**图片生成设置** 位于标签内容下方，是所有来源共用的画图通道选择，不随标签切换。

## 思考模式

页面顶部的 **思考** 为全局设置，对所有会话立即生效。可选：关闭、极低、低、中、高、极高。模型不支持时客户端会自动降级。

## 图片服务

在桌面端 **设置 → 模型 → 图片**，可以分别为文生图和图生图选择服务。自动选择仍优先使用内置 567 API；已有的模型、对话和图片记录保持不变。

若使用自己的 OpenAI 兼容图片服务，点击 **添加服务**，填写名称、Base URL、API Key 和准确的模型 ID，并勾选服务实际支持的模式。最多保存 20 个服务。示例 Base URL 为 `https://api.example.com/v1`：应用会分别请求其 `/images/generations` 或 `/images/edits`，无需填写具体端点。图生图要求该服务支持 OpenAI multipart 编辑协议，且一次使用一张参考图。

保存后仍需在对应模式的选择器中选用该服务。图片插件通过统一媒体接口使用它，不需要在插件中再填密钥。自定义服务的计费、尺寸和可用性由服务方决定。

API Key 加密存放在本机凭据库，界面只显示是否已配置。编辑时留空会保留原密钥；更换 Base URL 的来源时必须重新输入。保存失败会保留表单，可重试；关闭未保存表单和删除服务都需要确认。系统安全存储不可用时不会降级为明文存储。

## 验证配置

<Steps>
  <Step>
    ### 会话探测

    新建会话并显式选择该模型，发送一条短消息。
  </Step>
  <Step>
    ### 知识库探测

    若用于知识库加工，到 **设置 → 知识库设置** 选择处理模型后点 **测试连接**。
  </Step>
</Steps>

常见失败原因：Base URL 路径多写或少写、模型 ID 不存在、密钥无效、账户无权限、代理拦截、网络不可达。

<Checklist title="把模型用于真实任务前">
  <li>新建会话能够显式选择该模型，并完成一条短消息。</li>
  <li>切换默认模型后，新会话显示预期选择。</li>
  <li>模型能力标记与上游实际支持一致，没有依赖自动猜测。</li>
  <li>知识库、自动化或 Claw 使用的模型已在对应入口单独验证。</li>
  <li>配置文件和诊断信息中没有要提交到仓库的真实密钥。</li>
</Checklist>

<Callout title="密钥与配置文件" type="warn">
  不要把含密钥的 `models.json` 提交到仓库或粘贴到问题报告。需要排查时可在设置中导出诊断包（不含让你主动泄露密钥）。
</Callout>

## 预设服务商与 Magpie

**预设服务商** 区域显示公共模型目录。填写密钥并启用后，使用该账号实际返回的模型列表。开关停用时保留本机加密密钥、模型配置与默认选择，但不再将其模型列为可选项，也不能新设为默认；重新启用后恢复。

Magpie 是运行在本机的代理预设，默认地址为 `http://127.0.0.1:3425/v1`。先自行运行 Magpie，再启用该项；软件不会代为安装或启动代理。地址编辑只允许端口 1–65535，主机固定为 `127.0.0.1`。端口变更会先读取模型，失败不保存，弹窗保留输入供重试。567 API 分组和线路继续使用其专用设置区域。

模型行的 **测试连通** 只检查服务地址能否得到 HTTP 响应，不调用推理接口，也不证明密钥有效、模型有权限或可以完成推理。实际使用前仍按上面的会话探测步骤验证。
