## 能力类型

| 类型 | 作用 |
| --- | --- |
| 技能 | 任务指令与工作流提示 |
| MCP | 连接外部工具与数据源 |
| 插件 | 扩展桌面 UI 与 Agent 能力 |
| 套装 | 一次组织多项能力，安装时可勾选成员 |

## 从目标选择能力类型

| 你的目标 | 优先选择 | 原因 |
| --- | --- | --- |
| 让 Agent 遵循稳定方法 | 技能 | 以指令和流程指导一次任务 |
| 调用外部服务或数据 | MCP | 提供结构化工具连接 |
| 扩展桌面界面、文件或消息 | 插件 | 能进入宿主 UI 和 Agent 生命周期 |
| 一次安装一组协同能力 | 套装 | 统一发现和选择成员 |

如果只是需要外部 API，不要先写桌面插件；如果只是需要稳定提示流程，也不必引入 MCP 服务。

## 发现与我的

- **发现**：浏览可添加的能力（含推荐连接器等分组）。
- **我的**：管理已安装项：启用、停用、配置、更新、移除。

可搜索能力名称；卡片展示来源、版本、状态（如需配置、可更新、已启用）。

## 搜索 MCP 发现目录

在「发现」中，**MCP 发现目录**展示尚未审核的公开候选，和可安装能力分开展示。可组合选择主分类、功能标签、运行方式、平台、权限范围、认证要求和发布者类型；信息不足会标为「未知」，并不代表无权限或无需认证。

输入关键词后，应用会逐步搜索目标范围的名称、摘要及中英文文本，包括还没加载的页。界面先显示已找到的部分结果和扫描进度，完成后才给出最终数量。每个来源显示当前 60 条，可前后翻页；完整说明只在打开详情时读取，摘要之外的长描述不参与关键词搜索。

- **暂停与重试**：可以暂停扫描，已显示结果保留；重试复用已校验的缓存，只补齐缺失内容。出现失败时，当前结果不代表全目录。
- **切换条件**：更换关键词或筛选条件会取消旧搜索，旧结果不会混入新条件。
- **更新目录**：一次搜索固定同一份目录版本；点击刷新后使用新版本，避免把不同版本的页混在一起。
- **只读候选**：可查看说明、来源与文档，不能从发现目录直接安装。分类和权限描述是目录信息，不代表安全认证。技能与已审核 MCP 仍可按原流程安装。
- **离线与旧目录**：保留已经校验的缓存。尚未下载的页离线不可用，界面会提示部分失败；若来源尚未发布 v2，则使用旧协议。如果提示旧兼容目录已冻结，旧客户端只能看到以前的快照，新客户端继续使用 v2 全量目录。

每个来源的目录数据采用有限并发和约 200 MiB 的缓存预算，超过预算淘汰最久未使用的分片，不限制 v2 目录总容量，也不影响已安装能力或用户配置。

## 从市场或列表添加

<Steps>
  <Step>
    ### 打开详情

    在发现列表点击能力，右侧抽屉显示说明、来源、版本与权限等信息。
  </Step>
  <Step>
    ### 添加

    选择 **添加能力**。套装会弹出成员勾选（已安装且无需更新的成员不会重复安装）。
  </Step>
  <Step>
    ### 完成配置

    - MCP 可能要求填写凭证、或浏览器账户授权。
    - 插件安装后弹出 **启用与权限**：确认启用并逐项授权后才会生效。
  </Step>
  <Step>
    ### 在会话中验证

    回到会话，确认技能 / 工具 / 插件入口按预期出现。
  </Step>
</Steps>

## 添加能力菜单

点击 **添加能力** 可选择：

| 方式 | 说明 |
| --- | --- |
| 导入技能压缩包 | 本地 zip / tar.gz / tgz |
| 导入插件压缩包 | 本地 zip，根目录需含 `plugin.json` |
| 添加外置仓库 | GitHub `owner/repo`，仓库需包含 `.vetta/marketplace.json`，添加后立即同步 |
| 手动添加 MCP | 配置 STDIO 或 HTTP MCP 服务 |

只导入可信来源。外置仓库同步失败时，应用可能保留上次可用内容并提示错误。

567 Agent 官方来源（`Chinachani/567-agent-marketplace`）作为内置来源随应用提供，始终启用，不能停用或删除；自行添加的外置仓库可以随时停用或删除。

## 管理与排错

- **停用**：保留安装，暂停使用。
- **移除**：卸载本地安装内容。
- **更新 / 重载**：有新版本或开发调试时使用。
- 同一能力标识已被其它来源占用时，不会自动覆盖，需在详情中确认来源。
- MCP 产物写入 `~/.567agent/agent/mcp.json`；技能 / 插件分别落在 `~/.567agent/skills`、`~/.567agent/plugins` 等目录；安装索引见 `~/.567agent/abilities.json`。

需要开发插件时阅读 [插件开发](/plugins/overview/)；只连接工具服务时阅读 [MCP 连接器](/product/mcp/)。
